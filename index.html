Connect with GitHub

Submissions and results live in a private repository, so this page talks to GitHub with your own token. It is kept in this browser only.

  1. Create a fine-grained token with access to only .
  2. Permissions: Contents read and write, Actions read. Metadata read is added for you.
  3. You need to be a collaborator on the repository; ask its owner to add you.

Submit an app

Drop the app's folder or a .zip of it. The gates run in GitHub Actions: types, SDK usage, structure, secrets, and a click-every-button run against a fake tenant. The result shows up here in a few minutes.
