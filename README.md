# SDK app gates portal

The upload page for [SDK app gates](https://github.com/petersm05/sdk-app-gates) (a private repository).

This repository holds only the page. It contains no app code, results or credentials. The page talks to the private repository through the GitHub API, using the visitor's own token, so only its collaborators can upload apps or read results.

The source of truth is `docs/` in the private repository; copy changes here.
